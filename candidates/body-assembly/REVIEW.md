The GUI, durable runtime, model draft adapter, selected source reader, local draft proposals, evidence-memory contracts, communication codec, modular inspection and canvas capture now have executed connections. Library acquisition, arbitrary tools, source patch application, Base admission and self-promotion have no route in this assembly.

The world is an observed-record projection. It retains authenticated snapshot generation/revision and displayed record IDs; job pages and 32-record memory/proposal display limits are explicit. Grouping edges are display relationships, not inferred causal/evidential links. The canvas marker analyzer still uses the fixture palette, even when measuring actual assembly record markers. It is not semantic graph recognition or a general vision model. A changed world after a capture does not rewrite the captured frame's intended snapshot.

The memory repository is an exclusive observational sidecar using immutable full snapshots and a replaced HEAD pointer; it is not a second runtime SQLite actor or canonical memory owner. Capacity remains bounded by the inherited 256-node/8 MiB contract. Old snapshots and exports remain on disk without automatic eviction. Reference licensing/independence assertions remain unverified; all admitted records are private by default.

Legacy intake preserves an exact immutable database copy and row mapping; it is bounded, explicit and read-only. Active/journal-bearing databases refuse. It does not establish that a hostile concurrent writer could never evade stable-copy observations, nor implement a full transactional live chat migration or automatic rollback of the legacy app. Sources remain intact, providing the practical rollback boundary. Retained orphan copies are not automatically adopted into memory.

The mounted modular provider is a fixed read-only inspector behind the inherited catalog, work-order and lease checks. Those checks run in process. They are not an OS sandbox or measured package loader. No model can request its own grant through the exposed UI or output text.
